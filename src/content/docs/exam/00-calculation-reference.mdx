## 自然对数 $\ln$

对数运算一律用换底公式 $\log_{a}x=\dfrac{\ln x}{\ln a}$（常用 $\log_{10}x=\dfrac{\ln x}{\ln2+\ln5}$、$\log_2x=\dfrac{\ln x}{\ln2}$ 等）。其余数先分解质因数，按 $\ln(ab)=\ln a+\ln b$、$\ln\dfrac{a}{b}=\ln a-\ln b$ 计算。

| $x$ | $\ln x$ |
| --- | --- |
| $2$ | $0.6931$ |
| $3$ | $1.0986$ |
| $5$ | $1.6094$ |
