## 一、发射类别与带外发射

**发射类别（class of emission）** 是用一组标准符号来标示某次发射的一组特性，包括 **主载波的调制方式** 、 **调制信号的性质** 以及 **被发送信息的类型** 等。ITU 的发射类别标识可由若干符号组成，其结构本身也传达了技术含义：第一符号表示主载波的调制方式，例如 **A** 表示双边带调幅、 **J** 表示抑制载波的单边带调幅、 **F** 表示调频、 **G** 表示调相；第三符号表示所传信息的种类，例如 **A** 为可听电报、 **B** 为供自动接收的电报（数据）、 **E** 为电话、 **F** 为电视/传真。掌握这一结构就能理解业余无线电中常见的一组对应关系：

- **A1A** ：等幅电报（CW），载波被电键通断，对应调幅类的键控电报。
- **J3E** ：单边带话（SSB 电话），即抑制载波单边带调制后传输语音。
- **F3E** ：调频话，载波频率随语音变化。
- **F3F** ：以调频话为载机传输的 SSTV/ATV 图像（传真、电视类信息）。
- **F2B / G2B** ：以单边带或调频话为载机、再经副载波传送的 RTTY、PSK31 等数据信号，其中 RTTY 通常标识为 **F2B** ，PSK31 通常标识为 **G2B** 。

与发射类别密切相关的一个概念是 **必要带宽（necessary bandwidth）** ：它是指恰好足以传输信息、并满足规定质量和速率所要求的 **最低带宽** 。以此为基础， **带外发射** 指的是由于调制过程而产生的、刚超出 **必要带宽** 的一个或多个频率的发射，但 **杂散发射** 除外。要注意区分两者：带外发射紧邻必要带宽外侧、由调制本身产生；而杂散发射来自其他机制（如发射机振荡器的谐波、互调产物、泄漏等），并不依赖调制过程。把发射能量尽量限制在必要带宽之内，是无线电管理对电台技术特性的基本要求。

## 二、调制方式基础

业余无线电通信中最基本的三种调制是 **AM（幅度调制/调幅）** 、 **FM（频率调制/调频）** 与 **PM（相位调制/调相）** 。它们的共同点是只让载波的某一个参数随调制信号变化：

- **AM** 不改变载波的 **频率** ，而是让已调波的 **瞬时振幅与调制信号的瞬时值成正比** 。普通调幅波在频域上包含载波以及对称分布于其两侧的 **上边带** 与 **下边带** 。根据对载波和边带的不同处理，调幅可细分为：普通 **AM** （上下边带俱在、载波不受抑制，而 CW 实际上是一种键控形式的 AM）； **DSB-SC** （抑制载波双边带，常简称 DSB）；**SSB-SC** （抑制载波单边带，常简称 SSB、LSB 或 USB）； **VSB** （残留边带，仅让一个边带受部分抑制，模拟 ATV 有时采用）。
- **FM** 不改变载波的 **振幅** ，已调波的 **瞬时频偏与调制信号的瞬时值成正比** ；频偏的大小只由 **调制信号的幅度** 决定（调制频率只决定音调高低，不改变频偏量）。
- **PM** 同样不改变载波的振幅，其 **瞬时相移与调制信号的瞬时值成正比** （因此 PM 的瞬时频偏正比于调制信号的变化率，而非其瞬时幅度）。

从频域看单边带调制对语音频谱的搬运：经 **USB（上边带）** 发射机调制后，语音频谱被 **平移** 到载波位置上（各分量相对关系不变）；经 **LSB（下边带）** 发射机调制后，语音频谱被 **倒置并平移** 到载波位置上（即频谱沿频率轴翻转）。这也解释了为何不同边带的信号不能在同一频率上直接兼容。

在应用层面，不同频段与场景有约定俗成的调制选择： **FM** 广泛用于 VHF/UHF 本地通联，因其抗幅度噪声、话音饱满； **SSB** 则广泛用于 HF 话音通联，也用于长距离、弱信号下的 VHF/UHF 话音通联。与 FM 相比， **SSB 的主要优点在于发射带宽更窄** ，能更节省频谱；而 **FM 的主要缺点** 是它始终含有恒定不变的载波分量，即便静默时也发射功率，导致 **发射功率利用不充分** 。此外， **CW（等幅电报）** 指以电键通断等幅载波来发报，是发射带宽最窄的方式，远窄于单边带话、调频话与 ATV。单边带调制本身可纳入 AM 范畴（它是抑制载波、抑制一个边带的调幅），而线性调频、扩频、相移键控等则不属于 AM。正因 FM 话音信道带宽远超过传输莫尔斯电码的必要带宽，业余电台一般不用 FM 话来通联莫尔斯电码，否则不符合"把带宽保持在技术状态和业务性质所允许的最低值上"的管理要求。

## 三、边带选择与发射带宽

使用 SSB 时，上下边带的选择在不同频段已成惯例： **VHF/UHF 的 SSB 通联通常选用上边带（USB）** ；在  **$14\,\mathrm{MHz}$ 及以上的 HF 频段** 语音通信通常也选用 **上边带** ；而在 **$7\,\mathrm{MHz}$ 及以下频段** 则通常选用 **下边带（LSB）** 。其分界大致在 $10.1\,\mathrm{MHz}$：以下用 LSB、以上用 USB，这本质上是各国爱好者普遍接受并沿用至今的 **通联习惯** ，并非由传播特性决定。发起 SSB 呼叫时，与周边电台的频率间隔应至少为 **$2\,\mathrm{kHz}$ ~ $3\,\mathrm{kHz}$** ，以免相互重叠。

各种调制方式的 **实际发射带宽** 由信号本身决定： **SSB** 的带宽约等于其所传调制信号的带宽（话音约 $2.7\,\mathrm{kHz}$ ），调制信号带宽越宽则已调带宽越宽； **FM** 的带宽则同时取决于调制信号的 **最高频率** 与 **幅度** ，可用近似式 $B_n = 2(M+D)$ 估算，其中 $M$ 为最高调制频率、$D$ 为峰值频偏——最高频率越高、幅度（对应频偏）越大，带宽越宽。对发射机而言，若向话筒输入远超规定的音频电压（ **过激励** ），结果是信号 **失真** ，并产生大量谐波与互调产物，反而使发射带宽增加、通信质量下降，并不会延长通信距离，也通常不会直接烧毁末级器件。

## 四、莫尔斯电码的速度与带宽

莫尔斯电码的速度常用 **WPM（words per minute，每分钟词数）** 计量。其标准定义有两种等价表述：一是 **每分钟拍发的连续标准单词"PARIS"的个数** 即为 WPM；二是每分钟包含的"点"信号个数除以 $50$ 即为 WPM（因为 PARIS 一词合计恰为 50 个点的时值）。莫尔斯的时值以"点"为基准单位：一个 **点** 为 $1$，一个 **划** 为 $3$，字符内点划之间的间隔为 $1$，字符之间的间隔为 $3$，单词（组）之间的间隔为 $7$。

基于这一时值，CW 的必要发射带宽可用公式 $B_n = B \times K$ 计算，其中 $B$ 为波特率，由 WPM 换算为 $B = \dfrac{\mathrm{WPM}}{1.2}$；常数 $K$ 描述电码符号翻转时射频信号的边带滚降特性，原则是：对于 HF 等 **衰落信道** 取 $K=5$，对于 **非衰落信道** 取 $K=3$ 即可。

## 五、图像通信：SSTV 与 ATV

业余无线电中的 **慢扫描电视（SSTV）** 与 **无线电传真（FAX）** 的调制方式都是 **FM** （图像信息先变成音频基带，再经调制发送）。SSTV 传送的是 **逐行扫描的静止图像** ，而非活动图像；常见 Robot、Scottie、Martin、AVT、SC2、PD 等方式的区别在于 **像素分辨率、像素调制方法、行频、帧频** 等参数不同，以适应不同画质与环境。接收这些 SSTV 信号时，周期性的短促"咯、咯"声是 **行同步信号** 。

用个人电脑加普通话音收发信机进行 SSTV 的做法是：在短波波段，用 **FM** 将图像编码为音频基带、再用 **SSB** 完成频率搬移；在超短波波段，则用 **FM** 同时完成音频基带调制与复合调制。其 FM 基带电平约定为：白电平对应高频率 **$2300\,\mathrm{Hz}$** 、黑电平对应低频率 **$1500\,\mathrm{Hz}$**、同步电平为最低频率 **$1200\,\mathrm{Hz}$**（即亮度映射为频率）。若收到的图像出现水平粗黑条纹、上下半帧错位，说明双方行频、帧频一致但 **帧扫描初始时刻不同步** ；若图像左右倾斜呈平行四边形，则说明双方 **扫描行频不一致** 。

相比之下， **业余电视（ATV）** 需要占用 **$5\,\mathrm{MHz}$ 以上带宽** ，常规 ATV 通信不能在低于 $1.2\,\mathrm{GHz}$ 的业余频段进行，因为较低频段无法容纳如此宽的信号。模拟 ATV 有时用 **VSB（残留边带）** 传输：它属于 AM 范畴，仅发送一个完整边带以及另一边带靠近载波的一小部分，优点是 **较普通 AM 带宽更窄** ，且能 **确保视频低频分量的保真度** 。爱好者偶尔也用 FM 而非 VSB 传模拟 ATV，其优点在于 ATV 发射功率较小时，FM 解调能更好地去除叠加在信号上的外部调幅噪声。当需要经短波话音信道传送几张较高分辨率（如 1024×768）的电路图时，合适的选择是 **数字慢扫描电视（DSSTV）** 或 **无线电传真（FAX）** ，而非占用过宽或需高频段的 ATV，也非分辨率偏低的模拟 SSTV。
