在 CW（等幅电报）以及 SSB 等文字、话音通联中，爱好者大量使用 **Q 简语** 和 **英文缩语** 来缩短交换、跨越语言障碍。 **Q 简语** 是一组以字母 **Q** 开头的三字母简语，可在任何语种环境下通用；它作 **陈述句** 时表示某种状态，句末加 **问号** 则变为询问。下面先系统梳理最常用的 Q 简语与 CW 缩语，再讲解话音与 CW 两种模式的操作程序。

## 常用 Q 简语与 CW 缩语

### 功率、速度与收发状态

**QRP** 表示 **我已降低发射功率** ，也泛指 **小功率操作** ——爱好者以低于 5 瓦的功率开展通信研究或追逐奖状时，常直接在呼号后附加 **/QRP** （如 **BI9XYZ/QRP** ）来表明这一操作属性。与之相对， **QRO** 表示 **我要增加发射功率** ：通联中若对方反映信号不好、需要增加功率，可反问 **QRO？** ；若认为小功率已足以可靠联络、希望与对方协商降低功率，则发 **QRP？** （而不是"May I try QRO for you？"或"QRT for you"之类）。

**QRQ** 表示 **请加快发报速度** （ **PSE QRQ** ），其反问形式为 **QRQ？** ； **QRS** 表示 **请放慢发报速度** （ **PSE QRS** ），反问形式为 **QRS？** 。需要改频时则用 **QSY** ，而非 QRQ/QRS。注意 **QTR** 表示 **时间** ，并不是调节速度。

**QRT** 表示 **我要关闭收发信机了，再见** ，用于结束当天通联。结束前常先确认对方是否还有消息： **QRU？** 询问"你还有事（要发的消息）吗？"，对方若已无事则回 **QRU** （我无事）。 **QRX** 表示 **我将在稍后（或约定时刻）再次呼叫你** ，例如发 **QRX 30 MIN** 表示三十分钟后再叫你；它与表示改频的 **QSY** 不同，只是约定"回头再叫"，并不改变当前频率。 **QRL** 用于守听后询问 **频率是否被占用** （"频率是否空闲？"）。 **QRV** 表示 **我准备好收信了** ；在通联中也可用来表示"已准备好参与某项活动"，例如 **QRV IN WAPC？** 是相约对方参加"木兰围场-通联中国之省"这类业余无线电活动的用语。

### 呼叫、位置与身份

若发起呼叫时没听清对方呼号，可发 **QRZ？** 请求重发—— **QRZ** 的含义是 **"谁在呼叫我？"** （作陈述时表示"呼叫你的是……"）。介绍或询问位置时使用的是 **QTH** ： **QTH？** 询问对方电台位置，回答如"我的 QTH 是成都"（My QTH is Chengdu）。

### 信号质量、干扰与发报手法

常用 **Q 简语加 5 个等级** 来表示信号报告，其中 **QSA** 表示 **信号强度** 、 **QRK** 表示 **信号可懂度（清晰度）** ；两者各用 1~5 级回答，如 **QRK 5** 即完全清晰、 **QSA 5** 即信号极强。 **QSB** 表示 **你的信号正在衰落** （信号起伏、衰减）。通联中若想了解自己的信号是否受他台干扰，可问 **QRM？** ，告知对方遇他台干扰则发 **QRM** ；询问天电干扰用 **QRN？** ，告知则用 **QRN** 。关于发报手法与键控质量，有两组相关简语： **QSD** 表示 **你的电台存在键控缺陷** （如交流声、键击声、接触不良或发报手法不佳等），可针对具体字母指出问题（如 **QSD AT Y** 表示字母 Y 手法不好，或 **QSD PSE CK** 请检查键控）； **QSK** 则表示 **发报时，我能够在电码的间隙中听到电台的插入** （即具备"击穿式"全双工收听能力，可随时中断对方）。这里 **CK** 是"检查"（check）的缩语。

### 确认、通联与转信

**QSL** 表示 **我确认抄收了你所发送的消息** ；在爱好者语境中也引申为 **QSL 卡片** 的交换（ **QSL？** 即请求对方确认抄收）。 **QSO** 指 **我能够直接或通过他台转信通联（某个电台）** ，常用来描述一次当前的业余电台间联络（一次"通联"）。 **QSP** 表示 **我可以将你的消息转信至某个电台** （帮助他台中转），例如 **QSP ×××？** 询问对方能否把消息转给某台。 **QSX** 表示 **我正在守听……** ，例如请对方守听自己 7074 千赫的 FT8 操作可发 **QSX MY FT8 ON 7074 KHZ？** ，告知对方自己正在 7074 千赫守听 FT8 则发 **QSX FT8 ON 7074 KHZ** 。 **QSY** 表示 **我要改变发射频率至……千赫（或兆赫）** ，协商对方改频可发 **QSY nnnn KHZ（或 MHZ）？** 。（注意 **QRY**、**QSV** 都不是改频：QRY 另有含义，QSV 指发送一串 V 用以调谐测试。）若不了解对方抄收情况，可问 **HW?** ；对方用 **CPI** 替代"R"或"QSL"，意为"copied（已抄收）"。

### 其他较少使用的 Q 简语

**QRB** 询问两电台间的距离； **QRA** 询问电台名称； **QRD** 询问去向（从哪里来、往哪里去）； **QRH** 询问频率是否漂移； **QRI** 询问发射音调如何； **QSU** 表示"我将在此频率发送"； **QSS** 表示"我将使用……工作频率"。

### 问候、祝愿与结束

建立或结束联络时，爱好者约定了一系列简短祝愿语。 **73** 表示 **致以 best regards** ，是结束当前联络并互致美好祝愿时最常用的缩语（注意 **59** 是话音的两位 RS 信号报告、 **599** 是 CW 的三位 RST 信号报告、 **99** 都不是祝愿语，不可混淆）。 **GM / GA / GE / GN** 分别是 **早晨好 / 下午好 / 晚上好 / 晚安** 的缩语（good morning / afternoon / evening / night）。 **GL** 表示 **好运气** （祝愿对方好运、好成绩）， **GB** 表示 **再见** （goodbye）， **GLD** 表示 **高兴** （glad）， **HNY** 是 **新年快乐** （Happy New Year，常在每年 12 月下旬的 CW 联络中出现）。 **FB** 表示 **太棒了、业务精湛** （fine business）。结束联络时还常用 **CU、CU AGN** （see you / see you again，再见、回头见）。

### QSL 卡片与地址

交换 QSL 卡片时常涉及地址与信封术语。 **ADR** 或 **ADDR** 表示 **地址** （如 **UR ADR？** 询问对方 QSL 邮寄地址）。 **BOX** 或 **P O BOX** 表示 **邮政信箱** ； **BURO** 是 **QSL 卡片管理局** 的缩语，爱好者通过它批量、低成本地交换 QSL 卡片。 **SAE** 指 **写好收信人地址的信封** （self-addressed envelope）， **SASE** 指 **写好收信人地址并贴好邮票（或附有邮资）的信封** （self-addressed stamped envelope）——向境外电台索取 QSL 时附上 SASE，便于对方回寄。

### 操作动作与程序

发起呼叫使用 **CQ** （普遍呼叫）；发完一拍并 **守听任意电台** 用 **K** （"请回答"），若只守听 **通联中的对方电台** 、不邀请他人则用 **KN** 。 **AGN** 表示 **再次、重复** （如重报呼号或信号报告时）。 **SRI** 表示 **抱歉** （用于更正刚才发错的内容）。 **R** 源自 **Roger** ，是 **"已抄收/确认"** 的起始语，可主动开启新会话传达确认。 **UR** 表示 **你的 / 你是** ； **PSE / PLS** 表示 **请** （please，活跃通联气氛的祈使句中常用）； **ES** 表示 **和** （and）； **FER** 表示 **为了、对于** （for）； **HPE** 表示 **希望** （hope）， **HPY / HPI** 表示 **幸福** （happy）； **TU** 表示 **谢谢你** （thank you）， **TNX / TKS** 表示 **谢谢** （thanks）， **MNY / MNI TNX** 表示 **非常感谢** （many thanks）； **NW** 表示 **现在** （now）。称对方操作员为"老朋友、老伙计"（无关年龄，比喻亲密队友）用 **OM** （old man），而 **OP** 是 **操作员** （operator）本身。 **YL** 指 **女士（年轻女性操作员）** ， **XYL** 指 **妻子** （原为 ex-young lady，即已婚女性、电台主人的妻子）。 **WL** 表示 **将要** （will）。 **DE** 表示 **来自** （from，如 DE BH1ZZZ）， **DR** 表示 **亲爱的** （dear，尊称如 DR ZORK）， **DX** 表示 **远地电台** （distance，形容来自远方的信号或联络）， **AHR** 表示 **另一个** （another）。此外， **RPT / RPRT** 是"报告"（report，如信号报告）的缩语， **ABT** 表示"大约"（about）， **RMKS** 表示"备注"（remarks）， **WKD** 表示"已通联过"（worked）， **CUZ** 表示"因为"（because）， **WID** 表示"与、和"（with）， **VY** 表示"非常"（very）。在 CW 中连续发出 **SK** 表示 **结束当前联络** ，连发 **AS** 表示 **请稍等** 。这里"连发"是把两个字母当作 **一个整体符号** 拍发、中间不留字母间隔，书面记录时会在其上 **加一条横线** （记作 AS̄、SK̄）。这类加横线的符号叫 **程序符号（prosign）** ，含义与普通字母无关： **AS̄** 的电码是"滴答滴滴滴"（ `.-...` ），听起来和 A、S 两个字母连在一起完全一样，却 **不是"AS"这个缩语、更不是"亚洲"** ，而是独立的" **请稍等** "信号；同理 **SK̄**（ `...-.-` ）表示结束联络； **AR̄**（ `.-.-.` ）表示 **正式报文（电文）发完**，与 SK 的"结束联络"含义不同——AR 用于发送完整电报消息时标示"消息到此结束"。

### 通用业务、设备与天线术语

一些业务与设备术语也以缩语出现： **ARDF** 是 **业余无线电测向** （Amateur Radio Direction Finding，俗称"猎狐"）； **HST** 是 **快速收发报** （High Speed Telegraphy）； **FREQ** 是 **频率** （frequency）； **TEMP** 是 **温度** （temperature）； **GND** 是 **地面、接地** （ground）； **GMT** 是 **格林尼治时间** （Greenwich Mean Time，部分 DX 电台仍以它标注时间）； **WX** 是 **天气** （weather）；天线振子"单元"的缩语为 **EL / ELE / ELS** （element）。此外， **TVI** 指 **电视干扰** （Television Interference），是射频干扰（RFI）的一种常见形式。

电台设备的缩语有： **RIG** 表示 **设备（收发信机）** （如 **RIG X6200** ）； **RCVR / RX** 表示 **接收机** ， **XMTR / TX** 表示 **发射机** ， **XCVR / TXRX** 表示 **收发信机** ； **PWR** 表示 **功率** （ **PWR?** 询问、 **PWR ABT 10 W** 表示约 10 瓦）； **ANT** 表示 **天线** ； **NAME** 用于介绍名字； **MH** 是"米高"（meters high，天线架设高度，如 **ANT GP 50 MH** 即垂直接地天线高 50 米）。

探讨天线时常见以下缩写： **DP** 指 **偶极天线** （dipole）； **GP** 指 **垂直接地天线** （ground plane）； **VER** 指 **垂直天线** （vertical）； **LW** 指 **长线天线** （long wire）； **YAGI** 指 **八木天线** （一种以发明者命名的常见定向天线）； **BEAM** 泛指 **定向天线** （beam，波束天线）。需留意八木天线属于定向天线的一种，但二者并非完全等同；而"单元"虽可英译为 unit，天线振子单元的缩语约定用 **EL** 而非 UNIT。

## 话音与 CW 模式的操作程序

### 话音（电话）模式的操作程序

发起呼叫前先守听、确认频率空闲，是基本礼节。用话音询问频率是否被占用，应说"有人使用频率吗？"，对应的英文规范说法是 **"Is this frequency in use?"** 、 **"Is anyone at this frequency?"** 或 **"Anybody here?"** ；而 **"Calling you, Roger?"** 这类表达并不能正确表达"频率是否空闲"的询问。

**CQ** 普遍呼叫的标准话音方法（中英文皆可）：中文可报" **CQ CQ CQ，这里是 BH1ZZZ，Bravo Hotel One Zulu Zulu Zulu，BH1ZZZ 呼叫 CQ，听到请回答** "；英文为" **CQ CQ CQ, this is BH1ZZZ, Bravo Hotel One Zulu Zulu Zulu, BH1ZZZ calling CQ and standing by** "。呼叫某个特定电台时，应先重复对方呼号、再报自己呼号，例如" **BH8YYY，BH8YYY，BH8YYY，这里是 BH1ZZZ……BH1ZZZ 呼叫** "或英文" **BH8YYY, BH8YYY, BH8YYY, this is BH1ZZZ … BH1ZZZ calling you and standing by** "。

建立话音通信后，应首先交换信号报告，例如" **BH1ZZZ，你的信号 57。是否抄收？** "或" **BH1ZZZ, you are 57, QSL?** "（话音用两位 RS 报告，如 57）。

联络结束时，爱好者常用 **"Cheerio."** 、 **"Ciao ciao."** 、 **"До свидания(Do svidaniya)."** 等各自语言的"再见"短句，表达对对方的美好祝愿并互道再见。

### CW（文字）模式的操作程序

**CW（等幅电报）** 以莫尔斯电码进行文字通信，有自己的一套程序。回应 CQ 时，发送速度应 **确保自己能够完美抄写，但不高于对方的速度** ——不必追求某个固定速率。守听后确认频率空闲，CW 方式应使用 **QRL?** 。发起呼叫或回答前，还应把发射频率调到与对方信号 **零拍**——即两个信号差拍为零、音调完全一致，这样双方收发同频，对方才能在同一个频率上听到你。

CW 发起 CQ 的标准格式为" **CQ CQ CQ DE BH1ZZZ BH1ZZZ BH1ZZZ PSE K** "。呼叫特定电台则为" **BH8YYY BH8YYY BH8YYY DE BH1ZZZ BH1ZZZ BH1ZZZ PSE K** "。

给出信号报告可发" **UR RST 579** "或" **UR 579** "（CW 用三位 RST）。收到对方报告后，回应收妥并致谢可发" **R TKS FER RPT** "或" **R TKS FER RPRT** "。日常通联中感谢一次愉快联络可发" **TNX FER NICE QSO ES HPE CU AGN 73 TU** "；竞赛或 DX 通联中则常简回" **TU** "。

收到" **PSE QSL VIA BURO** "，意即请对方通过卡片管理局回寄 QSL 卡。

### 电键与话筒常识

发 CW 时，单靠手键不易稳定。许多爱好者改用 **电子键控器（electronic keyer）** ：它按设定好的节奏自动产生点（dit）和划（dah），并使两者的长度比例严格保持 $1:3$ 、间隔均匀，从而让发出的电码更规范、易读。

话音通联用的 **动圈话筒（dynamic microphone）** 内部是一片连在音圈上的振膜，置于磁路之中——其结构与扬声器（喇叭）异曲同工：声波推动振膜，音圈切割磁感线而感应出电压。另有 **驻极体/电容话筒** 靠振膜与固定极板间的电容变化拾音，灵敏度更高但需偏置供电。无论哪种话筒，初次使用都应先调好 **话筒增益（microphone gain）** ，过大易使发射机过激励、产生失真与邻道干扰。
