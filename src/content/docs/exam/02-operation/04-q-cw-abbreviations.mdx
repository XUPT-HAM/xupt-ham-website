---
title: 常用Q简语与CW通信缩语
description: 汇总业余无线电常用的 Q 简语与 CW 通信缩语及其含义和用法。
---

在 CW（等幅电报）以及 SSB 等文字、话音通联中，爱好者大量使用 **Q 简语** 和 **英文缩语** 来缩短交换、跨越语言障碍。 **Q 简语** 是一组以字母 **Q** 开头的三字母简语，可在任何语种环境下通用；它作 **陈述句** 时表示某种状态，句末加 **问号** 则变为询问。下面系统梳理业余无线电最常用的 Q 简语与 CW 缩语。

## 功率、速度与收发状态

**QRP** 表示 **我已降低发射功率** ，也泛指 **小功率操作** ——爱好者以低于 5 瓦的功率开展通信研究或追逐奖状时，常直接在呼号后附加 **/QRP** （如 **BI9XYZ/QRP** ）来表明这一操作属性。与之相对， **QRO** 表示 **我要增加发射功率** ：通联中若对方反映信号不好、需要增加功率，可反问 **QRO？** ；若认为小功率已足以可靠联络、希望与对方协商降低功率，则发 **QRP？** （而不是"May I try QRO for you？"或"QRT for you"之类）。

**QRQ** 表示 **请加快发报速度** （ **PSE QRQ** ），其反问形式为 **QRQ？** ； **QRS** 表示 **请放慢发报速度** （ **PSE QRS** ），反问形式为 **QRS？** 。需要改频时则用 **QSY** ，而非 QRQ/QRS。注意 **QTR** 表示 **时间** ，并不是调节速度。

**QRT** 表示 **我要关闭收发信机了，再见** ，用于结束当天通联。结束前常先确认对方是否还有消息： **QRU？** 询问"你还有事（要发的消息）吗？"，对方若已无事则回 **QRU** （我无事）。 **QRX** 表示 **我将在稍后（或约定时刻）再次呼叫你** ，例如发 **QRX 30 MIN** 表示三十分钟后再叫你；它与表示改频的 **QSY** 不同，只是约定“回头再叫”，并不改变当前频率。 **QRL** 用于守听后询问 **频率是否被占用** （"频率是否空闲？"）。 **QRV** 表示 **我准备好收信了** ；在通联中也可用来表示"已准备好参与某项活动"，例如 **QRV IN WAPC？** 是相约对方参加"木兰围场-通联中国之省"这类业余无线电活动的用语。

## 呼叫、位置与身份

若发起呼叫时没听清对方呼号，可发 **QRZ？** 请求重发—— **QRZ** 的含义是 **"谁在呼叫我？"** （作陈述时表示"呼叫你的是……"）。介绍或询问位置时使用的是 **QTH** ： **QTH？** 询问对方电台位置，回答如"我的 QTH 是成都"（My QTH is Chengdu）。

## 信号质量与发报手法

早期业余无线电文献中常用 **Q 简语加 5 个强度等级** 来表示信号报告，这组简语就是 **QSA** （信号强度）。 **QSB** 表示 **你的信号正在衰落** （信号起伏、衰减）。关于发报手法与键控质量，有两组相关简语： **QSD** 表示 **你的电台存在键控缺陷** （如交流声、键击声、接触不良或发报手法不佳等），可针对具体字母指出问题（如 **QSD AT Y** 表示字母 Y 手法不好，或 **QSD PSE CK** 请检查键控）； **QSK** 则表示 **发报时，我能够在电码的间隙中听到电台的插入** （即具备"击穿式"全双工收听能力，可随时中断对方）。这里 **CK** 是"检查"（check）的缩语。

## 确认、通联与转信

**QSL** 表示 **我确认抄收了你所发送的消息** ；在爱好者语境中也引申为 **QSL 卡片** 的交换（ **QSL？** 即请求对方确认抄收）。 **QSO** 指 **我能够直接或通过他台转信通联（某个电台）** ，常用来描述一次当前的业余电台间联络（一次"通联"）。 **QSP** 表示 **我可以将你的消息转信至某个电台** （帮助他台中转），例如 **QSP ×××？** 询问对方能否把消息转给某台。 **QSX** 表示 **我正在守听……** ，例如请对方守听自己 7074 千赫的 FT8 操作可发 **QSX MY FT8 ON 7074 KHZ？** ，告知对方自己正在 7074 千赫守听 FT8 则发 **QSX FT8 ON 7074 KHZ** 。 **QSY** 表示 **我要改变发射频率至……千赫（或兆赫）** ，协商对方改频可发 **QSY nnnn KHZ（或 MHZ）？** 。（注意 **QRY**、**QSV** 都不是改频：QRY 另有含义，QSV 指发送一串 V 用以调谐测试。）

## 问候、祝愿与结束

建立或结束联络时，爱好者约定了一系列简短祝愿语。 **73** 表示 **致以 best regards** ，是结束当前联络并互致美好祝愿时最常用的缩语（注意 **59** 是话音的两位 RS 信号报告、 **599** 是 CW 的三位 RST 信号报告、 **99** 都不是祝愿语，不可混淆）。 **GM / GA / GE / GN** 分别是 **早晨好 / 下午好 / 晚上好 / 晚安** 的缩语（good morning / afternoon / evening / night）。 **GL** 表示 **好运气** （祝愿对方好运、好成绩）， **GB** 表示 **再见** （goodbye）， **GLD** 表示 **高兴** （glad）， **HNY** 是 **新年快乐** （Happy New Year，常在每年 12 月下旬的 CW 联络中出现）。 **FB** 表示 **太棒了、业务精湛** （fine business）。

## QSL 卡片与地址

交换 QSL 卡片时常涉及地址与信封术语。 **ADR** 或 **ADDR** 表示 **地址** （如 **UR ADR？** 询问对方 QSL 邮寄地址）。 **BOX** 或 **P O BOX** 表示 **邮政信箱** ； **BURO** 是 **QSL 卡片管理局** 的缩语，爱好者通过它批量、低成本地交换 QSL 卡片。 **SAE** 指 **写好收信人地址的信封** （self-addressed envelope）， **SASE** 指 **写好收信人地址并贴好邮票（或附有邮资）的信封** （self-addressed stamped envelope）——向境外电台索取 QSL 时附上 SASE，便于对方回寄。

## 操作动作与程序

发起呼叫使用 **CQ** （普遍呼叫）；发完一拍并 **守听任意电台** 用 **K** （"请回答"），若只守听 **通联中的对方电台** 、不邀请他人则用 **KN** 。 **AGN** 表示 **再次、重复** （如重报呼号或信号报告时）。 **SRI** 表示 **抱歉** （用于更正刚才发错的内容）。 **R** 源自 **Roger** ，是 **"已抄收/确认"** 的起始语，可主动开启新会话传达确认。 **UR** 表示 **你的 / 你是** ； **PSE / PLS** 表示 **请** （please，活跃通联气氛的祈使句中常用）； **ES** 表示 **和** （and）； **FER** 表示 **为了、对于** （for）； **HPE** 表示 **希望** （hope）， **HPY / HPI** 表示 **幸福** （happy）； **TU** 表示 **谢谢你** （thank you）， **TNX / TKS** 表示 **谢谢** （thanks）， **MNY / MNI TNX** 表示 **非常感谢** （many thanks）； **NW** 表示 **现在** （now）。称对方操作员为"老朋友、老伙计"（无关年龄，比喻亲密队友）用 **OM** （old man），而 **OP** 是 **操作员** （operator）本身。 **WL** 表示 **将要** （will）。 **DE** 表示 **来自** （from，如 DE BH1ZZZ）， **DR**  表示 **亲爱的** （dear，尊称如 DR ZORK）， **DX** 表示 **远地电台** （distance，形容来自远方的信号或联络）， **AHR** 表示 **另一个** （another）。

## 通用业务与天线术语

一些业务与设备术语也以缩语出现： **ARDF** 是 **业余无线电测向** （Amateur Radio Direction Finding，俗称"猎狐"）； **HST** 是 **快速收发报** （High Speed Telegraphy）； **FREQ** 是 **频率** （frequency）； **TEMP** 是 **温度** （temperature）； **GND** 是 **地面、接地** （ground）； **GMT** 是 **格林尼治时间** （Greenwich Mean Time，部分 DX 电台仍以它标注时间）； **WX** 是 **天气** （weather）；天线振子"单元"的缩语为 **EL / ELE / ELS** （element）。

探讨天线时常见以下缩写： **DP** 指 **偶极天线** （dipole）； **GP** 指 **垂直接地天线** （ground plane）； **VER** 指 **垂直天线** （vertical）； **LW** 指 **长线天线** （long wire）； **YAGI** 指 **八木天线** （一种以发明者命名的常见定向天线）； **BEAM** 泛指 **定向天线** （beam，波束天线）。需留意八木天线属于定向天线的一种，但二者并非完全等同；而"单元"虽可英译为 unit，天线振子单元的缩语约定用 **EL** 而非 UNIT。
