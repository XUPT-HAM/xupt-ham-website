## 收发信机与系统组成

**收发信机（transceiver）** 是把 **接收机** 与 **发射机** 组合于一体的无线电通信设备。一个能工作的无线电接收系统至少包含 **接收天线** 与 **解调器** （以及后续音频处理）；一个能工作的发射系统至少包含 **射频振荡器** 、 **调制器** 与 **发射天线** 。实际的设备中还涉及电源等部件，但就"完成一次收/发"的功能链而言，天线、频率产生、调制/解调与辐射是关键环节。

业余收发信机的直流电源线应尽量 **短而粗** ，目的是减小发射时电源线上的 **IR 压降** （电流在导线电阻上产生的电压损失），保证末级得到稳定供电；这与"分流机箱射频电流"或"防摔"无关。车载电台的直流电源 **负极** 应接到电池负极或发动机接地带（车身金属搭铁），以建立良好的回流路径。若车载台出现随引擎转速变化的尖利啸声，其来源通常是 **发电机** （alternator）的整流谐波经电源窜入。

## 单工、双工与半双工

按通路两个方向的时序，工作方式分三类： **单工（simplex）** 指两个方向 **交替** 传输、同一时刻只能收或发，例如两台靠 PTT（按下即发射、松开即接收）切换收发状态的对讲机之间的直接联络。 **双工（duplex）** 指两个方向 **同时** 传输，例如由一台 $430\,\mathrm{MHz}$ 接收机与一台 $144\,\mathrm{MHz}$ 发信机组成的地面台与业余卫星之间的联络（收、发在不同频段上并行进行）。 **半双工（semi-duplex）** 指链路一端为单工、另一端为双工，典型例子是 **中继台（双工）与靠 PTT 切换的对讲机（单工）** 之间的联络。具备 QSK 功能的 CW 收发信仍属单工（只在电码间隙短暂收听）。

## PTT、静噪、音量等面板功能

**PTT（Push-To-Talk，按键发射）** ：有信号（一般对地接通）时，发射机由等待状态转为发射。

**SQL（Squelch，静噪）** ：调整 **静噪阈值** ，作用是 **在没有信号时关闭音频输出** ，避免扬声器放出刺耳的背景噪声；它并不滤除信号中的噪声，也不做自动增益控制。聆听非常微弱的 FM 信号时应 **关闭静噪或将阈值设为 $0$** ，让音频输出不受限制。FM 接收中，对方松开 PTT 时偶尔听到短促"嘶/喀拉"噪声拖尾，是因为静噪电路要依据鉴频输出的高音频噪声来判断信号消失，这一检测需要时间，导致短暂噪声泄漏——属正常现象。

**VOL（Volume，音量）** ：调节接收机输出声音大小。

**VOX（Voice-Operated Transmit，声控）** ：根据对话筒有无语音输入来自动控制收发转换，实现"免提"，在双手忙碌时便于通联。

**NFM / WFM** ： **NFM** 为窄带调频（适用于信道带宽 $25\,\mathrm{kHz}$ / $12.5\,\mathrm{kHz}$ 的通信信号）， **WFM** 为宽带调频（适用于带宽约 $180\,\mathrm{kHz}$ 的广播信号），二者不可混用。手持/车载台的"全频偏/半频偏"选项对应与 $25\,\mathrm{kHz}$ 或 $12.5\,\mathrm{kHz}$ 带宽相匹配的 **$5\,\mathrm{kHz}$ 或 $2.5\,\mathrm{kHz}$ 调制频偏**——若别人报告你 FM 频偏过大，可切到 NFM 档，或讲话时离话筒远一些以减小频偏。

## 亚音调、双音多频与选通

**CTCSS（Continuous Tone-Coded Squelch System，亚音调静噪）** ：从 $67\,\mathrm{Hz}$ ~ $250.3\,\mathrm{Hz}$ 的 $38$ 个亚音调中选取一个作为选通信号叠加在语音上，接收机只有收到特定亚音调才打开音频输出，用以避免同频不同组之间的相互干扰。

**DTMF（Dual-Tone Multi-Frequency，双音多频）** ：由 $8$ 个音调频率中任取两个组合成控制信号，代表 $16$ 种状态，常用于遥控、中继遥切或传输简单字符。

与亚音选通对应的菜单项是 **CTCSS** （模拟亚音）与 **DCS** （Digital Coded Squelch，数字亚音）；DTMF 用于拨号/遥控而非静噪选通，SQL 是普通静噪。

## 常见故障排查举例

当对方报告你的 FM 信号失真严重、可辨度差时，可能原因包括：电源电压不足、所处位置 **多径衰落** 严重、或发射频率不准；可检查供电、挪动位置或校正频率后再试。若别人报告你的发射干扰了相邻频率，应检查 **发射机频率指示是否准确、杂散发射指标是否合格** 。若 2 米波段信号本很强却突然变弱难以辨别，多是 **多径效应** 引起的信号衰落或解调失真，可稍移位置改善。如需快速回到常用频率，应将该频率 **存储为一个频道（channel）** 。

## 中继台的双工器与互调

业余 **中继台** 通常在同一副天线上同时进行接收（上行）与发射（下行），因此需要在接收机、发射机与天线之间插入 **双工器（duplexer）** 。它本质上是一组 **滤波器** ：允许发射机的下行信号送到天线，同时阻止该强信号反馈进入本台接收机，避免收发自激。仅用收发转换开关无法在连续转发时兼顾收发隔离；功率分配器用于分配功率而非隔离；环形器是单向器件，而双工器多用腔体滤波器实现所需的收发隔离。

双工器依赖 **收发隔离** （上下行频率间隔足够、或用滤波器/空间隔离）。若隔离不良，本台发射信号窜入接收机，会出现"被上行信号启动后持续发射不停"的 **自锁** ；若下行信号与附近其他发射机信号在接收机前端非线性电路中混合，产生等于上行频率的 **互调干扰** ，则上行信号消失后仍会断续发射、夹带模糊话音。当中继台被断断续续干扰打开静噪、但守听显示上行频率并无台在工作时，往往是附近两部发射机的强信号在接收机中产生了"等于上行频率"的互调产物，而非人为恶意干扰或本机寄生振荡。这正是架设中继台前必须排查台址附近其他发射机、防止其信号与本站下行信号产生落入上行频率的互调的原因。

在发射机与双工器之间串接 **铁氧体隔离器（isolator）或环行器（circulator）** （多余端口接匹配负载）可阻断反向信号、降低两部发射机末级相互混频产生互调的概率，是减小中继台互调干扰的常用手段。

**互调（intermodulation）** 指两个或多个强信号同时进入非线性电路（接收机前端、馈线、双工器等）时产生新的频率分量。其中 **三阶互调产物** 落在 $2f_1 - f_2$ 与 $2f_2 - f_1$ 处（$f_1,f_2$ 为参与的信号频率）。若中继台发射频率为 $f_T$ 、接收频率为 $f_R$ ，附近另一部发射机频率为 $f_X$ ，要使其三阶互调产物落入上行（接收）频率，则令 $2f_T - f_X = f_R$ 得 $f_X = 2f_T - f_R$ ，或令 $2f_X - f_T = f_R$ 得 $f_X = (f_T + f_R)/2$ 。即可能造成干扰的频率为 $2f_T - f_R$ 或 $\dfrac{f_T + f_R}{2}$。

> 例题：架设业余中继台之前必须调查台址附近有没有其他频率的发射机，其信号强到可以在中继台的接收机中与中继台的下行信号产生三阶互调，并且互调产物落入中继台的上行频率范围内。如果中继台的上、下行频率分别为 $f_R$ 和 $f_T$，则可能造成这种三阶互调干扰的频率 $f_X$ 可以计算为？
>
> 三阶互调产物落在 $2f_1 - f_2$ 与 $2f_2 - f_1$ 处，令其等于上行频率 $f_R$ 。
> - 令 $2f_T - f_X = f_R$，得 $f_X = 2f_T - f_R$ ；
> - 令 $2f_X - f_T = f_R$，得 $f_X = \dfrac{f_T + f_R}{2}$ 。
>
> 结论：可能造成干扰的频率为 **$2f_T - f_R$ 或 $\dfrac{f_T + f_R}{2}$** 。

## 接收机与发射机的功能电路与增益控制

嘈杂环境下改善 SSB/CW 话音抄收，可用 **耳机** 贴近耳朵替代扬声器，减少环境噪声混入。

面板常见缩写中， **NB（Noise Blanker，抑噪）** 用于切除高于平均信号的大幅度突发脉冲噪声（如汽车点火、火花塞干扰）； **SQL（Squelch，静噪）** 在信噪比达不到阈值时自动关闭音频输出。两者不同：NB 针对脉冲噪声、SQL 针对整体静噪。遇到火花塞脉冲干扰使 AGC 过早起控、压制 SSB/CW 信号时，应 **打开 NB** 。 **MODE** 用来切换工作方式（FM、LSB、USB、CW 等）。

**ATT（Attenuator，输入衰减器）** 在接收大信号时接入，使信号不致过大使前级过载。 **AGC（Automatic Gain Control，自动增益控制）** 对中频级信号电平检测并反馈控制，防止电路过载。为何还要 ATT：特强 **带外** 信号可阻塞接收机前级使其非线性工作、产生失真与互调，此时需在前端加衰减器（ATT 是直接在前端衰减，AGC 是后级增益控制，解决不了前端阻塞）。 **过载** 即输入过强使电路饱和阻塞、严重可损坏前端；启用 ATT 可缓解（而不是减小音量，也不是电源电流过大）。 **应关闭 AGC** 的情形是有用微弱信号与强干扰同时出现——AGC 会拉平强弱使弱信号更难辨，关掉可保留弱信号动态。 **AGC 时间常数** ：接收 FM/FSK/PSK 等 **包络恒定** 信号选 **较短** ；接收 SSB/AM 等 **包络不断变化** 的信号选 **较长** （避免音量随语音忽大忽小）。

**PRE（Preamp，前置放大器）** 在接收微弱信号时接入（接入后某些指标可能低于额定值，噪声系数改善但动态范围下降）。**ALC（Automatic Level Control，发信自动电平控制）** 对射频输出电平检测并反馈控制，维持其在适当限度内；在 SSB 中主要是 **防止过驱动导致调制失真或电路故障** 。即便开了 ALC，把 **话筒增益调得过高** 仍会使发出信号失真；对方若反映你话音间隙夹带背景噪声，应调低话筒增益，若有语音压缩则调低压缩深度。用 SSB 发 **AFSK** （如 RTTY/PSK 经 SSB 发射）时应 **关闭 ALC** ，因为 ALC 会增加 AFSK 信号失真、抬升误码率。

**语音压缩（PROC）** 压低较强语音幅度、提升较弱语音幅度，改善弱语音在接收端的信噪比（并非压缩频谱宽度，也非压低低频）。调整不当时会产生大量 **互调成分** ，影响对方辨识。发 AFSK 时也应关闭语音压缩，否则包络畸变会破坏基带特征、抬升误码率。

增益控制策略上， **射频/中频增益** 处于前端、影响信噪比与动态范围， **音频增益** 只影响响度。信号特弱时尽量把 **射频/中频增益开到最大** 以获最佳信噪比，再调音频增益得适当音量；信号特强时先把 **音频增益开到最大** ，再用射频/中频增益限制输入、避免过载。

**AT / TUNE（自动天线调谐）** 检测天线电路 VSWR 并自动补偿以维持最小驻波比。发射测量功率/驻波比时，必须先将频率设到 **无人使用的空闲频率** 、偏离常用热点频率，避免干扰他人；测试连续信号的正确做法是将电台设为 **CW 并按下电键** （或 AM/FM 按下 PTT 不对话筒说话）产生连续载波，结束后设回 SSB。

在话筒/耳机音频电缆外 **穿套铁氧体磁环** ，可抑制电缆感生的共模射频电流（共模扼流）。 **HF 与 VHF/UHF 最大不同** 在于 HF 通信主要依靠 **电离层反射** 传播，而 VHF/UHF 多为视距或有限散射，传播特性差异显著。
