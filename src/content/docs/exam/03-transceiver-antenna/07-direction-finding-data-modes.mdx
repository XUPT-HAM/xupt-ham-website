# 测向与常见数据模式信号

## 业余无线电测向

**业余无线电测向（ARDF，Amateur Radio Direction Finding）** 是利用接收设备测定隐蔽发射台方位的体育活动与技术，也常用于定位有害干扰（ **QRM** ）。适合爱好者组织比赛或用于定位 QRM 的活动就是业余无线电测向本身；扫频多普勒探测、回波定位、单/多基地 PSD 分析等属于其他专业探测手段，不属于这类大众活动。

进行 ARDF 时，与接收机配合最关键的器材是 **定向天线** ——它能在不同方向上呈现不同的接收强度，从而判断来波方向。射频电桥、噪声电桥、SWR 电桥等是用来测量阻抗或驻波的仪器，不能用来测向。

需要特别注意的是，业余测向中使用的 **隐蔽台属于业余无线电台设备** ，其设置和使用必须向无线电管理机构提出申请并获得批准，并非免执照可任意使用的玩具或单纯体育器材，性能指标也需经检测合格。

国际业余无线电联盟（IARU）测向锦标赛规则中， $144\,\mathrm{MHz}$ 测向发射机采用调幅度 $70\%$ ~ $80\%$ 的 **A2A 调制** 方式（即调幅载波上叠加音频摩尔斯电码），以 $8\,\mathrm{WPM}$ ~ $15\,\mathrm{WPM}$ 发出台标识，这类发射的占用带宽不得大于 **$6\,\mathrm{kHz}$** 。

## 测向天线及其近场特性

80 米波段的测向机接收天线多为 **环形天线与鞭状天线的组合** ：环形天线主要感应信号的 **磁场** 分量，鞭状天线感应 **电场** 分量，两者合成可得到具有单向性的 **心形方向图** 。但在逐渐接近发射台时，远处调好的方向性会变差，需要重新调整鞭状天线长度——原因是：在 **远场区** ，空间的 **波阻抗** 几乎恒定；而进入 **近场** 后，波阻抗随距离的变化越来越大，单纯按远场调好的幅相比已不再适用。

160/80 米波段有时用 **磁棒天线** （类似中波收音机）替代带屏蔽的环形天线：把磁棒上的线圈 **中置** 时，其接收特性与环形天线相近，且设备更 **小巧** ；但在接近发射台时，非屏蔽磁棒会因 **电容感应** 影响方向性，要求选手熟练应对。需要注意的是，磁棒并非靠“饱和”来充当自动增益或衰减器。

两米波段 ARDF 接收机有时只选配仅有 **驱动和反射两个单元的二单元八木天线** ：二单元天线仍具有一定单向性且更轻便，对熟练选手依然实用；在近场区选手常利用天线的 **零点（接收最弱方向）** 来辅助定位，此时单元数量并不关键。

**HB9CV 天线** 是一种常用于两米波段测向的自制天线，属于 **双驱动单元八木天线** ：其引向器与反射器通过移相跳线以 **$225\degree$ 分相** 方式馈电；它带宽较宽、水平与垂直方向单向特性理想、便于携带，且可良好匹配（并非 SWR 居高不下），也完全可用于正常通联。

## 常见数据模式信号的频谱特征

在 HF 数据通信段用 SSB 方式收听，不同数字模式会呈现不同的“声音”和频谱样貌，可据此识别：

- 听到 **两个音调以一定速率交替变化** 的信号，使用的是 **RTTY** （用两个音频音调的频移来代表二进制，属于 AFSK）。
- 听到 **音调不变但似乎不断轻微颤动** 的信号，使用的是 **BPSK31 或 QPSK31** （PSK31 是相位键控，单载波的相位连续微变，听感像颤动）。FT4 是短促突发、SSTV/FAX 是扫描音，与此不同。
- 听到 **音调周期性变化、且每个周期中伴有“笃、笃”或“咯、咯”声** 的信号，使用的是 **SSTV（慢扫描电视）或 FAX（传真）** ，其扫描音随行/帧周期起伏。PSK31 与 RTTY 不符合该听感。

把信号显示在频谱仪或 SDR 瀑布图上，各模式的谱线形态更加直观：

- **CW（等幅报）** ：表现为 **一条闪动的垂直线** ——单个载频，只在按键发报的瞬间出现、松键时消失。
- **RTTY** ：表现为 **两条闪动的垂直线** ——对应两个交替的音频音调。
- **SSB 话音** ：表现为 **一组随语音出现和变化的非对称垂直线** ——只有单边带，谱线分布不对称。
- **AM 话音** ：表现为 **一条固定的垂直线（载波）左右对称伴随一组随语音变化的垂直线** ——载波始终存在，两侧是对称的上下边带。
- **FM 话音** ：中心有一条载波垂线，两侧对称伴随一组随语音出现和变化的边带（调制越深边带展开越宽）。
- **PSK31** ：表现为 **一个宽度很窄的单峰** ——相位键控信号能量高度集中在单一载频附近，占用带宽极窄。
