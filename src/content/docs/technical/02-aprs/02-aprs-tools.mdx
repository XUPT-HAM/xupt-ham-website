## 地图网站

### aprs.fi

- 全球最流行的 APRS 地图服务，输入呼号即可查看台站**实时位置、轨迹、历史记录**，支持搜索、气象台数据、台站收听列表等。
- 网址 [aprs.fi](https://aprs.fi/)，适合在电脑/手机上"看"全网 APRS 台站。

### aprs.tv

- 国内 APRS 地图服务（基于百度地图等），提供**极速浏览、热力图、信标分级显示、轨迹追踪**等功能，对国内访问更友好。
- 网址 [aprs.tv](https://aprs.tv/)。

> 两者本质都是 APRS-IS 的"地图终端"：从服务器拉取实时数据并在地图上展示。

## 客户端软件

### APRSdroid（Android）

- 老牌 Android 开源 APRS 客户端（GPLv2）。
- 支持多种连接：**蓝牙串口连 TNC**、**AFSK 音频连电台**、或直接走 **APRS-IS 上网**。
- 功能：上报位置信标、查看附近台站、收发 APRS 消息。

### APRSLocus（Android / Windows 等）

- 国产**开源 APRS 客户端**（作者 BG7LZQ，GPL-3.0，Flutter 开发），官网 [aprslocus.theez.top](https://aprslocus.theez.top/)。
- 支持 Android、Windows 等多个平台。
- 功能丰富：**实时台站追踪、轨迹回放、热力图、多种地图底图（高德/OSM/Esri 等）、消息收发（含群聊）、信标上报、设备识别**等，中文界面友好。

## 小结

- 只想"看"全网台站 → **aprs.fi / aprs.tv**；
- 手机上报位置、收发消息 → **APRSdroid** 或 **APRSLocus**；
- 想要现代界面与更丰富功能 → **APRSLocus** 是不错的选择。
