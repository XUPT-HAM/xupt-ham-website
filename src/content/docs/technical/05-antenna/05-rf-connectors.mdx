射频连接器外形看着都差不多，但**螺纹在内还是在外**、**中心是针还是孔**只要错一个就装不上，硬拧还可能顶坏中心导体。判断公母的可靠方法是看**中心导体**：中心为凸出金属针的通常称"公（Male / Plug）"，中心为凹陷插孔的称"母（Female / Jack）"；再看外壳螺纹方向。业余设备统一使用 **$50\,\Omega$** 阻抗。

## SMA 与 RP-SMA 的四种组合

SMA（SubMiniature version A）是手台、SDR 与无线模块上最常见的小型螺纹连接器，螺纹规格 $1/4$-$36\,\mathrm{UNS}$，常规型号可用到 $18\,\mathrm{GHz}$。为符合 FCC 等"避免用户随意更换高增益天线"的要求，WiFi 设备引入了把针孔对调的 **RP-SMA（Reverse Polarity SMA）**，于是市场上共有四种外形几乎一样、却两两不兼容的接头：

| 名称（常见代号） | 外壳螺纹 | 中心导体 | 必须对接 |
| --- | --- | --- | --- |
| 标准 SMA 公（SMA-J / SMA Male / SMA-P） | **内螺纹**（可旋转螺母） | **针** | 标准 SMA 母 |
| 标准 SMA 母（SMA-K / SMA Female） | **外螺纹** | **孔** | 标准 SMA 公 |
| 反极性 RP-SMA 公（RP-SMA-J） | **内螺纹** | **孔** | 反极性 RP-SMA 母 |
| 反极性 RP-SMA 母（RP-SMA-K） | **外螺纹** | **针** | 反极性 RP-SMA 公 |

换句话说：标准 SMA 是"内螺纹 + 针 / 外螺纹 + 孔"，RP-SMA 是"内螺纹 + 孔 / 外螺纹 + 针"。同为公母、但标准与反极性之间即便能拧上，也无法形成正确的射频通路，还会损伤中心接触件。

<Aside type="caution">
    **字母代号并不统一，别只看型号里的字母。** 国内连接器行业常把 J 叫"公"、K 叫"母"（如 SMA-J 公针、SMA-K 母孔）；而日系/台湾天线型号用的是 P / J（Plug / Jack），**SMA-P 才是公**、**SMA-J 是母**——例如钻石官方把 SRH770S 的接口写作 "SMA-P"（SMA 公），而适配宝锋的 SRJ77 是 SMA 母。采购时一律以实物的"螺纹内外 + 针/孔"为准。
</Aside>

## 手台上常见的两种搭配

- **机身 SMA 公 + 天线 SMA 母**：泉盛 UV-K1/5/6、宝锋 UV-5R 系列等国产手台多为这种，机身是一个带内螺纹、中心有针的凹陷天线座；钻石 **SRJ77** 就是专门配这类机型的 SMA 母天线。转接外接天线时也需要 "SMA 母转 SO-239" 一类转接头。
- **机身 SMA 母 + 天线 SMA 公**：多数日系手台，以及钻石 **SRH771 / SRH770S**、老鹰 RH771 的 SMA-P 版本属于这种。买之前先低头看一眼自己机身的天线座。

## M 头 / UHF 连接器（PL-259 与 SO-239）

- 这一系列名称很多：**UHF 连接器、M 头、M 座、PL-259、SO-239** 指的都是同一种螺纹式连接器，是 HF 与 VHF 设备、馈线、天线及驻波表上最普遍的接口。
- **PL-259 = 公头（插头）**，装在电缆端，带可旋转的内螺纹螺母与中心针；**SO-239 = 母座（插座）**，固定在电台背板或天线底座上，带外螺纹。外壳螺纹为 $5/8$-$24\,\mathrm{UNEF}$，中心针直径约 $0.156$ 英寸（约 $4\,\mathrm{mm}$）。
- 名称里的 "UHF" 是历史遗留：该连接器诞生于 20 世纪 30 年代，当时把 $30\,\mathrm{MHz}$ 以上称作 UHF；其特征阻抗并非恒定，一般建议用于 $300\,\mathrm{MHz}$ 以下，短波与 $144/430\,\mathrm{MHz}$ 完全够用，优点是结实、耐功率、便宜。
- 手台接外置天线或馈线时，宜用 "SMA 转 SO-239" 的**短跳线**而非刚性转接头，避免把手台天线座别坏。

## BNC

- **BNC（Bayonet Neill–Concelman）** 采用**卡口式**锁紧：插入后旋转约四分之一圈即可锁定，无需拧螺纹，插拔迅速。
- 有 $50\,\Omega$ 与 $75\,\Omega$ 两种规格，业余无线电用 $50\,\Omega$；常见于早期手持机、扫描接收机、测试仪器与馈线转接。部分手台天线（如 RH771 的 BNC 版本）也用它。

## 其他常见接口

- **N 型**：螺纹式、尺寸比 SMA 大，阻抗恒定 $50\,\Omega$，带密封圈可户外防水，适合 UHF/微波、长馈线或大功率场合。
- **TNC**：BNC 的螺纹版本，抗振性好，多见于专业设备与部分手持机。
- **MMCX / MCX**：更小的推入式连接器，用于 SDR、GPS 模块与小型设备内部，不耐反复插拔。
- **$3.5\,\mathrm{mm}$ 音频、RJ45 话筒、USB-C、HDMI** 等虽不是射频接口，但常与电台同机出现，整理接口清单时也要一并区分。

## 选购检查清单

1. 先看**设备端**：螺纹在内还是在外、中心是针还是孔。
2. 再确认**天线/电缆端**与之互补（内螺纹配外螺纹、针配孔）。
3. 确认是**标准 SMA 还是 RP-SMA**（手台几乎都用标准 SMA，RP-SMA 多见于 WiFi 路由器）。
4. 确认**阻抗 $50\,\Omega$**，以及耐功率、频率范围是否满足需求。
5. 需要跨接口时优先用**短跳线（尾线）**过渡，减少对手台天线座的杠杆应力。
