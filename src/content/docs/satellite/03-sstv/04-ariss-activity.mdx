ARISS（Amateur Radio on the International Space Station，国际空间站业余无线电）是让国际空间站（ISS）搭载业余电台、开展通联与教育活动的计划。本文只讲 ARISS 特有内容，SSTV 的原理与解码请见前几篇。

## ISS 常见 U/V 段频率与模式

| 用途 | 频率 | 说明 |
| --- | --- | --- |
| 语音（学校通联/随机通联）下行 | **145.800 MHz** | FM，全球通用收听频率 |
| V/U FM 语音中继（跨段） | 上行 145.990 MHz（亚音 67.0 Hz）→ 下行 437.800 MHz | 太空中的 FM 中继台 |
| APRS 数字中继 | **145.825 MHz**（上下行） | 分组 / APRS digipeater |
| SSTV 下行 | **145.800 MHz** | 图片活动期间下发 |

> ISS 呼号常用 **NA1SS**（美）、**RS0ISS**（俄）、**DP0ISS / OR4ISS / IR0ISS**（欧）等；具体频率与启用状态以 ARISS 当期公告为准。

## 下发功率

- ISS 业余电台下行功率通常为 **5 W** 左右（FM），加之地空路径损耗，地面用八木天线 + 手台即可收到。

## 下发图片周期

- SSTV 活动期间，ISS 会以约 **2 分钟一张** 的节奏循环下发图片（模式如 PD120 / Robot36 等），并穿插间歇，便于地面多次接收、获取更清晰的图像。

## 如何获取电子版奖状（证书）

- 接收 ISS SSTV 图片后，可到 ARISS 官网（ariss.org）或相关 SSTV 画廊提交接收到的图片 / 日志，申请**电子版参与证书**。
- 学校通联（ARISS School Contact）的收听者也可申请**收听证明 / 电子证书**，具体以 ARISS 当期活动说明为准。

## 如何获取纸质版 QSL 卡

- 完成收听 / 通联后，向 ARISS 邮寄**收听报告**（含呼号、日期、UTC 时间、频率、模式、内容、设备、信号报告等）。
- 附上**回邮信封**（写清收信地址、贴足邮资；国际邮件需附国际回信券 IRC 或航空信封），寄往 ARISS 指定地址。
- 经核实后会寄回**纸质 QSL 卡**。地址与要求请以 ARISS 官网当期公布为准。

## 小结

守听 ISS 是 U/V 段最有成就感的活动之一：用一根八木 + 手台即可收到来自空间站的语音、APRS 与 SSTV 图片，还能兑换电子证书与纸质 QSL。
