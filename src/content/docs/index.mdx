## 什么是业余无线电

业余无线电（Amateur Radio）是由经批准、对无线电技术有兴趣的人员，利用无线电频谱进行的**双向通信与技术实践**活动。它既是个人爱好，也是跨越百年的通信技术，更是一支关键时刻能挺身而出的公益力量。

<CardGrid>
	<Card title="红色的电波记忆">
		从革命战争年代起，无线电就是传递信念的桥梁。隐蔽战线上的无线电工作者（如电影《永不消逝的电波》中李侠的原型——李白烈士）用电台向组织传递情报，在黎明前献出生命；"滴答"声中传递的是忠诚、担当与对胜利的坚定信念。
	</Card>
	<Card title="航天与授时的基石">
		为给我国第一颗人造卫星"东方红一号"提供精密时间，1966 年国家启动"326 工程"，建成短波授时台 BPM 与长波授时台 BPL，此后为火箭、卫星发射与国防建设提供毫秒级、微秒级授时保障，奠定今日国家授时体系的基础。
	</Card>
	<Card title="应急通信的生力军">
		在汶川地震等重大灾害中，当常规通信瘫痪时，业余无线电爱好者第一时间架起电台，为灾区传递救援信息、搭建"生命电波"，成为政府应急通信的有力补充。
	</Card>
</CardGrid>

<Aside type="tip">
	五九电波社传承的，正是这种"忠诚、担当、奉献"的电波精神。欢迎你加入，一起学习、一起动手、一起在需要时挺身而出。
</Aside>

## 关于我们

西邮五九电波社（Five-Nine Radio Wave Club）是西安邮电大学面向全校学生的业余无线电兴趣社团。我们以「推广业余无线电、普及通信知识、锤炼动手实践能力」为宗旨，为同学们搭建从电台通联、电子与通信技术、卫星遥感与天文学的实践平台。

<Aside>目前该群暂以同好会形式运行，我们计划在2027级新生入学前找到20位发起人，注册为校内正式社团，望各位师傅多多支持！</Aside>
