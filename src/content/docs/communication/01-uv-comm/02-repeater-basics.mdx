中继台（Repeater）架设在高处，接收一个频率（上行）并用另一频率（下行）转发，从而扩大覆盖范围。要让手台"上中继"，需要正确设置几项参数。

## VFO 模式与 MR 模式

- **VFO 模式（自由调频）**：直接输入频率，适合临时测试、手动调频。
- **MR / 信道模式（存储）**：把常用频率连同差频、亚音等参数存进信道，日常通联直接选信道即可。
- 建议把常去的中继台存成信道，用 MR 模式调用，避免每次重复设置。

## 上行与下行、上下差

- **下行频率**：中继台发射、你接收的频率（听这个频率）。
- **上行频率**：你发射、中继台接收的频率（发这个频率）。
- 上行与下行通常相差一个固定值，称为**差频 / 上下差（Offset）**：
  - U 段常见差频 **±5 MHz**（个别 ±7.6 MHz 等）；
  - V 段常见差频 **±0.6 MHz（600 kHz）**。
- 方向：若上行比下行高，记为"**+**"；低则记为"**−**"。设置时需同时设对**差频方向**与**差频大小**。

## CTCSS 亚音（哑音）

- **CTCSS**（连续音频编码静噪系统）是在语音上叠加一个低频音频（67–254 Hz），中继台只有检测到正确的亚音才转发。
- 常见亚音如 **T88.5（88.5 Hz）**、**T79.7（79.7 Hz）**、T67.0 等。**T88.5 即 88.5 Hz 的 CTCSS 亚音**。
- 手台上常标注为 **T-CTCSS / TX CTCSS / T-SQL** 等；通常只需设置**发射亚音**即可"打开"中继。

## 中继台类型（查询时注意）

- **模拟中继**：传统 FM 中继，需设差频 + 亚音（CTCSS/DCS）。
- **数字中继**：如 **DMR、D-STAR、C4FM（YSF）** 等，需设对应制式与色码/时隙等，普通模拟手台无法互通。
- **混合中继**：同一频率既转模拟又转数字。
- **APRS 中继（Digipeater）**：数字分组中继，与语音中继不同，用于 APRS 数据转发。
- **直频（Simplex）**：不经中继、双方同频收发。

## 如何查询中继台

- 本地无线电协会 / 无委公告；
- **RepeaterBook** 等中继数据库网站 / App（可按城市筛选频率、差频、亚音、制式）；
- 向本地火腿、社团群询问常用的中继频率与参数。

## 上中继小贴士

- 听清下行再发射，避免"只发不收"；
- 报呼号、简洁通联，让出间隙；
- 用对亚音和差频，否则中继"打不开"。
