C4FM（4 电平频移键控）是 Yaesu（八重洲）**System Fusion（Fusion）**系统采用的数字语音调制方式。

## 特点

- 提供**数字语音**（清晰、无噪声）与**数据传输**（呼号显示、定位、文本消息等）。
- 自动选择：数字对数字、模拟对模拟，兼容传统 FM 通联。
- 配合 **WIRES-X** 可经互联网联通全球节点。

## 使用

- 需要支持 Fusion 的 Yaesu 电台（如 FT-70、FT-5D、FTM 系列等）；
- 也可通过 **MMDVM 热点**接入数字网络，与 DMR/D-STAR 等互通。
