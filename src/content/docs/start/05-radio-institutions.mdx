办理操作证、设台领呼号、参加考试，都会接触到若干无线电管理机构。理清它们的职责，能少跑弯路。

## 工业和信息化部（工信部）

- 国家层面的**无线电管理主管部门**，制定《中华人民共和国无线电管理条例》《业余无线电台管理办法》等法规、政策与规划。
- 在陕西省的对应机构是**陕西省工业和信息化厅**（省工信厅），统筹全省无线电管理工作。

## 无线电管理委员会（无委）

- 如**陕西省无线电管理委员会（办公室）**，是省内的无线电管理机构，负责**频率指配、台站审批、呼号指配、执照核发**，以及监督检查与行政执法。
- 通俗理解："无委"管的是**行政审批与执法**——设台申请、领呼号、办执照都经它办理。

## 无线电监测站（无测）

- 如**陕西省无线电管理委员会办公室西安市监测站**（省无委办/省工信厅的派出机构）、**陕西省无线电监测站**。
- 负责**频谱监测、查找干扰源、测定设备技术指标**等技术支持工作。
- 西安的 A/B 类操作证考试，实际就是由**西安市无线电监测站**组织实施的（报名、设考点、安排考试）。

## 协会 / 学会（业余无线电协会）

- **中国无线电协会业余无线电分会（CRAC）**：全国性业余无线电组织，负责 **C 类考试组织、题库审定、操作证书与呼号信息管理**等。
- 省/市级的**无线电协会、业余无线电协会**：组织本地培训、活动、比赛，协助考试报名等，是爱好者之间的桥梁。

<Aside type="tip">
    西安的协会不像其他省各地的无线电协会，可以自由入会，缴费入会后还能优先抢考试名额、有小周边小礼品等。西安这些啥都没有，就是交50块钱入一个微信群，群内偶尔会组织些活动，比如给操作证考试当监考志愿者等。
</Aside>

## 一句话区别

| 机构 | 关键词 | 和你相关的典型事务 |
| --- | --- | --- |
| 工信部 / 省工信厅 | 主管、立法、政策 | 顶层法规与规划 |
| 无委（无委办） | 审批、执法 | 设台、呼号、执照 |
| 无测（监测站） | 监测、检测、干扰查找 | 组织本地 A/B 类考试 |
| 协会（CRAC 等） | 行业组织、服务 | C 类考试、题库、活动培训 |

> 简单记：**要办证、设台找"无委"；要考试看"无测"组织的通知；了解规则、参加活动找"协会"；法规源头是"工信部"**。
